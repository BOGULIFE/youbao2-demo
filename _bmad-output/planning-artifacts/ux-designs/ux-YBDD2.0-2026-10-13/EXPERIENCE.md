# EXPERIENCE · FR-022 首页金刚区

**冲突规则：** 本文件与 [DESIGN.md](DESIGN.md) 定义 FR-022 的 C 端体验合同；未覆盖的首页行为沿用 [FR-021 EXPERIENCE](../ux-YBDD2.0-2026-10-07/EXPERIENCE.md)。FR-022 PRD 是需求真源，若与 mock 冲突，以 PRD 和本合同为准。

## Foundation

- **Form-factor：** 移动端 App 主画布，逻辑宽度 390px；桌面评审仍使用居中手机画布。
- **UI system：** 沿用 FR-021 DESIGN tokens（橙系 C 端、浅灰页面底、白色卡片）；金刚区只增加 FR-022 专属组件规则。
- **Auth：** C 端默认已登录；点击人数仅按登录用户 `userId` 去重。
- **Surface：** 金刚区是首页 `home` Tab 的普通滚动模块，不是底栏入口、浮层或全屏子页。
- **Source of truth：** C 端只消费首页 BFF 下发的有效 `quickEntries[]`，不在客户端拼接或覆盖入口配置。

## Information Architecture

### C 端一级结构

FR-021 的五个底栏 Tab 不变：首页仍为 `home`，金刚区插入首页内容流：

```text
顶栏 → Banner → 金刚区 → 三格数据 → 新手学院/活动中心
→ 设置工作台 → 榜单 → 找项目 → 右豹动态 → OPC 服务机构 → Footer
```

### 金刚区入口数据

每个有效入口至少包含：

| 字段 | 用途 | C 端行为 |
| --- | --- | --- |
| `entryId` | 稳定身份 | 点击和历史数据归属，不因文案修改变化 |
| `configVersion` | 配置版本 | 随点击事件上报，用于报表追溯 |
| `icon` | 图标资源 | 加载失败时使用默认图标或隐藏单项 |
| `title` | 主标题 | 必填，单行省略，作为无障碍名称 |
| `subtitle` | 副标题 | 可选，单行省略 |
| `jumpType` | 跳转类型 | 决定站内或受控外部打开方式 |
| `jumpTarget` | 跳转参数 | 由服务端校验后下发 |
| `sort` | 展示顺序 | 升序渲染，不在客户端重新排序 |

## Voice and Tone

- 入口标题短、直接，以动作或功能名为主，例如“活动中心”“找项目”“工具市场”；正式文案由后台配置。
- 错误提示说明下一步，不暴露内部路由、配置版本或接口错误码。
- 保存即生效属于后台操作反馈，不在 C 端提示。
- C 端不展示点击次数、点击人数、统计时间范围等运营指标。

## Component Patterns

### 金刚区渲染

- BFF 返回至少一个有效入口时渲染容器。
- 入口按 `sort` 升序排列；相同排序由服务端稳定处理，客户端不自行猜测。
- 第一版采用 4 列网格，最多 8 个入口、最多两行；入口尺寸和容器高度稳定，避免内容刷新时布局跳动。
- 少于 4 个入口左对齐，不补空占位；只有 1 个入口也保持入口单元尺寸，不拉伸为大按钮。
- 入口超过 8 个时，当前 UX 合同要求后台在保存时拦截；若未来开放“更多”，需另开 UX 变更，不默认在客户端截断。

### 点击与跳转顺序

用户点击入口后按以下顺序执行：

1. 生成本次点击的唯一 `eventId`，读取当前入口 `entryId` 与 `configVersion`。
2. 异步发起点击上报，不阻塞跳转。
3. 执行服务端已校验的站内路由或受控外部跳转。
4. 将可获得的跳转结果补充到事件；若结果无法同步回写，至少保留初始点击事件。

点击与跳转互不吞并：跳转失败仍计入点击次数，并记录 `jumpResult=failed`。

### 配置更新感知

- 已打开的首页不主动打断用户；刷新首页或重新进入首页时读取最新有效配置。
- 配置更新后，旧页面点击旧入口时仍按页面持有的 `configVersion` 上报；服务端根据 `entryId` 保留历史归属。
- 入口停用或过期后，新进入首页不再展示；已离开首页的旧页面不要求强制弹窗。

## State Patterns

| 状态 | 入口区行为 | 用户反馈 |
| --- | --- | --- |
| Loading | 显示不超过最终高度的轻量 skeleton，或延迟渲染模块 | 不阻塞 Banner 和首页滚动 |
| Loaded 1–8 | 展示固定尺寸网格 | 可点击 |
| Empty | 不渲染金刚区 | 首页内容自然衔接，不显示大空态 |
| Partial invalid | 隐藏缺失/非法单项，保留其他有效项 | 不向用户暴露配置错误 |
| Icon failed | 使用默认图标或隐藏单项 | 其他入口不受影响 |
| API failed | 隐藏模块或保留轻量占位 | 不阻塞其他首页模块 |
| Disabled/expired | 新进入首页时不下发 | 无入口残留 |
| Tap pending | 入口保持视觉稳定，允许跳转 | 上报在后台异步处理 |
| Jump success | 进入目标页 | 返回栈沿用现网路由 |
| Jump failed/forbidden | 留在首页 | Toast/轻提示说明无法打开 |

## Interaction Primitives

- **Tap：** 整个入口单元为一个可点击区域，最小触控区域不小于 44×44px；图标和文字不拆成多个点击目标。
- **Press feedback：** 使用轻微背景/透明度变化，不改变尺寸，不触发持续动画。
- **Scroll：** 金刚区随首页纵向滚动，不吸顶、不悬浮、不遮挡底栏或今日路径气泡。
- **Retry：** 点击上报失败由客户端异步重试；用户不需要重复点击入口。
- **Toast：** 仅用于跳转失败、无权限或目标不可用等可行动反馈；不展示内部错误码。
- **Navigation：** 站内目标进入对应页面；外部目标进入受控 WebView/浏览器容器，具体承载沿用现网能力。

## Analytics Trigger Contract

### Click event

点击事件在用户完成入口触控确认时生成，不以页面曝光或跳转成功作为前置条件。事件至少携带：

```text
eventId
entryId
configVersion
userId
source = home_jingang
position
clickTime
jumpType
jumpResult
```

### Counting behavior

- 点击次数：同一用户对同一入口的重复点击按多次计数。
- 点击人数：在报表选定范围内，对同一 `entryId` 的 `userId` 去重；同一用户点击不同入口分别计入各入口人数。
- 上报重试：同一 `eventId` 只接受一次，避免重复计数。
- 跳转失败：保留点击事件，`jumpResult` 标记失败。
- 未登录用户：第一期不计入点击人数，不在 C 端自行生成匿名身份。

## Accessibility Floor

- 整个入口单元使用一个语义化可聚焦控件，`aria-label` 为“标题”，有副标题时为“标题，副标题”。
- 图标加载失败时，标题仍能独立表达入口含义。
- 文案不以颜色作为唯一信息；禁用和错误状态同时通过可读提示或可感知的控件状态表达。
- 入口触控区域不小于 44×44px；焦点态不能被白色卡片背景吞掉。
- 动效只提供短暂按压反馈；支持减少动态偏好，未配置动效时仍可完成点击和跳转。
- 页面滚动和底栏安全区不因金刚区新增而产生遮挡。

## Key Flows

### Flow 1 · 小周从首页进入高频功能

1. 小周打开已登录的首页。
2. Banner 下方出现 1–8 个有效金刚区入口。
3. 小周点击“活动中心”入口，客户端生成 `eventId` 并异步上报。
4. App 打开活动中心；若目标不可用，留在首页并提示原因。

**Climax：** 小周从首页一跳进入目标功能，点击行为可在后台按入口核对。

### Flow 2 · 配置更新后的返回首页

1. 运营保存入口排序或启停配置，后台反馈“已保存并生效”。
2. 小周当前已打开的首页不被强制打断。
3. 小周返回首页或重新进入首页时，读取最新有效入口顺序。
4. 已停用入口不再展示；保留入口的历史 `entryId` 不变。

**Climax：** 配置即时生效与用户当前操作互不干扰。

### Flow 3 · 空配置和异常降级

1. 首页接口返回空数组、全部入口非法或金刚区接口失败。
2. 首页隐藏金刚区，不显示大块空卡。
3. Banner 后直接衔接三格数据，其他模块正常加载。

**Climax：** 金刚区是可插拔增强，不会把首页变成错误页。

## Responsive & Platform

- **390px 手机画布：** 4 列、最多两行，左右 12px 页面边距。
- **窄屏：** 入口标题优先保留，副标题可隐藏；不得缩小到低于 44px 触控区域。
- **桌面评审壳：** 入口仍相对于手机画布布局，不按浏览器宽度拉伸为多列。
- **横屏或系统字体放大：** 入口固定高度不被撑破；若标题无法容纳，使用省略并通过无障碍标签保留完整读法。
